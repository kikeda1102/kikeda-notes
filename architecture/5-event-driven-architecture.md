# イベント駆動アーキテクチャ

イベント駆動アーキテクチャ（EDA: Event-Driven Architecture）とは、システム内のコンポーネントが「イベント」の発行と購読を通じて非同期に連携するアーキテクチャパターン。

## 背景

従来のAPIによるリクエスト/レスポンス型の通信では、
- リクエスト送信側がレスポンスを待つ同期的な処理では、システム間の依存関係が強くがち
- マイクロサービス的な構成では、1つのサービスの障害が他のサービスに波及しやすい


## 基本概念
- システムで発生する出来事や状態の変化を「イベント」として表現
- プロデューサーとコンシューマーという、非同期にイベントを処理する分離されたコンポーネントで構成
- イベントの発行と購読を通じてコンポーネント間の結合度を低く保つ

### イベント
- システム内で発生した出来事や状態の変化を表す情報の単位

イベントの例: 
- ユーザーアカウントを作成した
- ユーザーが商品を購入した
- 在庫が更新された
- 支払いが完了した
- 配送が開始された
